# anyone-can-build-coffee

일본에서 카페가 **어떤 장비와 방식으로 커피를 내리는지**(반자동·전자동 에스프레소 머신, 핸드드립, 사이폰, 프렌치프레스, 에어로프레스 등) 가기 전에 확인할 수 있는 영어·일본어 카페 리스트를 기획하는 취미 프로젝트예요.

A hobby project planning a bilingual (EN/JA) list of cafes in Japan that shows how each cafe brews its coffee — which espresso machine, which brewing method — before you go.

## 현재 상태

- **기획 단계.** 최신 문서는 [PRD v0.4](docs/prd/PRD-v0.4.md)예요.
- 다음 단계는 **M0 조사**(4주)예요. 인터뷰 3명, 카페 30곳 불확실성 테스트, 공유 리스트 반응을 봐요. 진행 기준을 통과해야 개발(M1)을 시작해요.

## 기획 방식

1. PRD를 쓴다.
2. C레벨 페르소나 5명(CEO·CPO·CMO·CFO·CTO)이 **서로 맥락 없이 PRD만 보고** 적대적으로 리뷰한다.
3. 창업자가 지적마다 동의 · 일부 · 반대로 판정하고 메모를 남긴다([review-docket.html](docs/review-docket.html)). 판정 데이터 자체는 이 레포에 없어요.
4. 판정을 반영해 다음 버전을 쓴다. 반대한 지적은 PRD에 이유와 함께 남긴다.
5. 전략이 안정되면 planner가 "바로 만들 수 있나"를 점검한다.
