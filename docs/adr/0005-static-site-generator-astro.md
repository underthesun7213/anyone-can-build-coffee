# ADR-0005: 정적 사이트 생성기로 Astro를 쓴다 (정적 출력, UI 프레임워크 없음)

- 상태: 제안됨
- 날짜: 2026-11-20 (웹 사실 확인일 동일)
- 근거: [PRD v0.6](../prd/PRD-v0.6.md) §7, §8 F1·F2·F6·F7, §9, §10, §11 / 비교: [tech-stack.md](../architecture/tech-stack.md) §3~§4
- 관련: [ADR-0001](0001-static-site-and-light-pwa.md), [ADR-0002](0002-four-sheet-data-model-and-csv-build.md), [ADR-0006](0006-hosting-github-pages.md)

## 배경

PRD §11은 "정적 사이트 생성기"를 쓴다고만 정했다. 생성기는 다음을 해내야 한다.
- 한 소스에서 `/en/`, `/ja/` 페이지를 모두 생성하고, 언어별 제목·설명을 붙인다(§10).
- CSV 4개를 조인해 카페·체인마다 페이지를 만든다(SC-03, SC-06).
- 기기에서 도는 작은 JS를 붙인다(F1, F2, F6, F7).
- 무료 정적 호스팅에 올릴 수 있어야 한다.
- 무엇보다 학부생 한 명이 배우고 유지할 수 있어야 한다.

후보 네 개(Astro, Eleventy, Vite + 직접 쓴 스크립트, Hugo)를 비교했다. 가중 점수는 Astro 4.40, Hugo 3.50, Eleventy 3.45, Vite + 스크립트 3.45였다. 기준·근거·출처는 tech-stack.md에 있다.

## 결정

1. **Astro를 정적 출력 모드로 쓴다.** 어댑터와 on-demand 렌더링은 쓰지 않는다.
2. **UI 프레임워크 통합(React, Vue, Svelte 등)을 쓰지 않는다.** 클라이언트 동작은 `.astro` 파일의 `<script>`에 순수 TypeScript로 쓴다.
3. 라우트는 `src/pages/[lang]/…`와 `getStaticPaths()`로 언어(`en`, `ja`) × id 조합을 만든다. 루트 `/`는 정적 페이지 하나에 작은 인라인 스크립트를 넣어 언어를 고른다(localStorage → 브라우저 언어 → `en`). `<noscript>`에는 두 언어 링크를 둔다.
4. CSV 읽기, 조인, `station_id` 계산은 **프레임워크와 무관한 `src/lib/` 모듈**에 둔다. 검증 스크립트(`scripts/validate-data`)도 같은 모듈을 쓴다. Astro 쪽은 이 모듈의 결과만 받는다. 그래야 나중에 생성기를 바꿔도 데이터 코드는 그대로 남는다.
5. service worker와 manifest는 플러그인 없이 `public/`에 직접 둔다(ADR-0001).
6. `package-lock.json`을 커밋하고 Astro 버전을 고정한다. 메이저 업그레이드는 필요할 때만, 별도 브랜치에서 한다.

## 고려한 대안

| 대안 | 기각 이유 (요약) |
|---|---|
| Eleventy (2026-03 "Build Awesome"으로 이름 변경, 안정 v3.1.2, v4 알파) | 단순하지만 템플릿 언어 선택과 pagination 기반 페이지 생성이 처음 배우기에 덜 직관적이다. 클라이언트 JS 번들러가 없다. 이름·버전 과도기다. **2순위**로, Astro 업그레이드 부담이 커지면 옮길 후보 |
| Vite + 직접 쓴 생성 스크립트 | 의존성은 가장 적지만 라우팅·i18n·페이지 생성·이스케이프를 직접 만들어야 해서 작은 SSG를 새로 짜는 셈이다 |
| Hugo (v0.170.1) | 다국어는 가장 강하다. 하지만 Go 템플릿과 Hugo 고유 개념의 진입 장벽이 높고, CSV가 기본으로 행 배열이라 시트 간 조인이 번거롭다 |

## 결과

**좋은 점**
- HTML에 가까운 문법이라 시작하기 쉽다. 기본 출력에 JS가 없다.
- 공식 문서에 CSV 로더(`file()` + parser) 예제와 i18n 라우팅 안내가 있다.
- 클라이언트 TS를 Vite가 번들·최소화해 준다.

**나쁜 점 / 감수할 것**
- 메이저 버전 주기가 빠르다(2026-01에 6 베타, 2026-11에 7.4.x). 업그레이드할 때 깨질 수 있다. 버전 고정과 최소 기능 사용으로 줄인다.
- 2026-01 Cloudflare가 Astro 팀을 인수했다. MIT 라이선스와 호스팅 중립을 유지한다고 발표했지만, 장기 방향은 지켜봐야 한다.
- Node.js와 npm 의존성 관리가 필요하다(Hugo의 단일 바이너리와 비교).
- 브라우저 언어 감지는 정적 출력에서 프레임워크가 해 주지 않는다. 그래서 루트 이동은 직접 스크립트로 한다.
