# ADR-0007: 지도는 Leaflet과 OpenStreetMap 타일로 그린다

- 상태: 승인됨 (2026-11-27, 창업자)
- 날짜: 2026-11-27 (웹 사실 확인일 동일)
- 근거: [PRD v0.6](../prd/PRD-v0.6.md) §4(지도를 v1로 옮김), §8 F10 · [02-design](../plans/02-design.md) §2.6 · [ADR-0003](0003-coordinates-from-osm-not-google.md)

## 배경

- 창업자가 지도를 v1에 넣기로 했다. 위치는 목록 위(SC-01), 마커를 누르면 작은 팝업과 상세 링크가 뜬다.
- 사이트는 정적 사이트(ADR-0001)이고, 좌표는 OSM이나 공개 주소의 지오코딩에서만 가져온다(ADR-0003). 구글 지도는 데이터 저장이 약관상 막혀 있어 쓰지 않는다.
- 카페는 25~30곳, 방문자는 주 100명 정도를 목표로 한다. 규모가 작다.

## 결정

1. **라이브러리는 Leaflet 1.9.4**(버전 고정)를 npm으로 넣는다. 지도 스크립트는 목록 페이지에서만 불러온다.
2. **타일은 OpenStreetMap 공식 타일**(`tile.openstreetmap.org`)로 시작한다. [Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/)를 지킨다.
   - 지도 위에 "© OpenStreetMap contributors" 출처를 **항상 보이게** 둔다. 보통 오른쪽 아래이고, UI로 가리거나 토글 뒤에 숨기지 않는다.
   - 지금 보고 있는 영역의 타일만 받는다. **미리 받기, 오프라인용 받기, 대량 받기는 하지 않는다.** PWA 서비스 워커가 생기더라도 타일은 캐시 대상에서 뺀다.
   - 캐시를 막는 헤더(`no-cache`)를 보내지 않는다. 브라우저 기본 동작을 그대로 쓴다.
3. **마커는 에스프레소 상태 배지와 같은 토큰과 아이콘**을 쓴다(`L.divIcon`). 반자동·전자동·없음이 색과 모양으로 구분된다.
4. **팝업**에는 카페 이름, 에스프레소 배지, 상세 링크를 넣는다.
5. **카페 상세 페이지에는 지도를 넣지 않는다.** 길찾기 버튼이 구글 지도로 경로를 열어 주므로, 작은 지도는 정보를 더하지 않는다. 이는 창업자의 질문 "길찾기가 필요한가, 유용한가"에 대한 판단이다.
6. **지도가 실패해도 목록은 그대로 쓸 수 있다.** 스크립트나 타일이 안 되면 지도 영역에 안내 문구만 보인다.

## 고려한 대안

| 대안 | 기각 이유 |
|---|---|
| MapLibre GL + 벡터 타일 | 더 매끄럽고 다크 모드 지도도 가능하다. 하지만 라이브러리가 무겁고 타일 제공처가 따로 필요하다. 카페 30곳에는 과하다 |
| 구글 지도 임베드/JS API | 키와 요금이 필요하다. 지도 데이터를 저장·재사용하는 데 약관 제약이 있다(ADR-0003) |
| 카페 상세에도 작은 지도 | 길찾기 버튼과 역할이 겹친다. 나중에 필요하면 같은 컴포넌트로 추가한다 |

## 결과

**좋은 점**
- 비용이 0원이고 키가 필요 없다. 좌표 출처(OSM)와 지도 출처가 같다.
- Leaflet은 가볍고 문서가 많아 학부생 혼자 유지하기 쉽다.

**감수할 것 / 다시 볼 때**
- OSM 공식 타일은 SLA가 없고, 정책을 어기면 예고 없이 막힐 수 있다. 트래픽이 늘거나 오프라인 지도가 필요해지면 정책이 허용하는 타일 업체로 바꾼다. 후보는 [Raster tile providers](https://wiki.openstreetmap.org/wiki/Raster_tile_providers)에 있다. 그때 이 ADR을 대체하는 새 ADR을 쓴다.
- 래스터 타일이라 다크 모드에서 지도 자체는 밝게 보인다. 마커와 컨트롤만 토큰을 따른다.
- 지도에 "내 위치"는 F1(위치 권한, 거리순)과 함께 넣는다.
